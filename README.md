# 🤖 Discord Bot

Бот с модерацией и музыкой на `discord.py`.

## Установка

### 1. Установи зависимости

```bash
pip install -r requirements.txt
```

### 2. Установи FFmpeg

Музыкальный модуль требует FFmpeg.

- **Windows**: Скачай с https://ffmpeg.org/download.html и добавь в PATH
- **Linux**: `sudo apt install ffmpeg`

### 3. Создай бота в Discord Developer Portal

1. Перейди на https://discord.com/developers/applications
2. Создай новое приложение → Bot
3. Включи **Message Content Intent** и **Server Members Intent**
4. Скопируй токен

### 4. Настрой токен

Открой файл `.env` и вставь свой токен:

```
DISCORD_TOKEN=твой_токен_здесь
```

### 5. Запусти бота

```bash
python bot.py
```

## Команды

### 🛡️ Модерация
| Команда | Описание |
|---------|----------|
| `/kick <участник>` | Выгнать участника |
| `/ban <участник>` | Забанить участника |
| `/unban <User#1234>` | Разбанить участника |
| `/mute <участник> [минуты]` | Замутить участника |
| `/unmute <участник>` | Снять мут |
| `/clear [количество]` | Удалить сообщения |

### 🎵 Музыка
| Команда | Описание |
|---------|----------|
| `/join` | Зайти в голосовой канал |
| `/play <запрос>` | Играть музыку |
| `/pause` | Пауза |
| `/resume` | Продолжить |
| `/skip` | Пропустить трек |
| `/stop` | Остановить и выйти |
| `/queue` | Очередь треков |
| `/nowplaying` | Текущий трек |
| `/volume <0-100>` | Громкость |
